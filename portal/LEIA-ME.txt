CONNECT PLUS — PORTAL DO CLIENTE

Endereço publicado
https://connectplusautomacao.github.io/connectplus-site/portal/

Esta pasta contém a versão visual atualizada do portal. Para aplicá-la no site,
substitua os arquivos index.html, portal.css e portal.js na pasta /portal do
repositório GitHub e confirme o commit. O cabeçalho usa a logomarca horizontal
ConnectPlus_Logo_Horizontal_Site.png e o ícone oficial favicon-connectplus-transparente.png,
que já ficam na raiz do repositório.

Arquivos
- index.html e portal.css: identidade visual atualizada e responsiva.
- portal.js: acesso Supabase, recuperação de senha, projetos, atualizações e documentos.
- A migração SQL e o código-fonte da Edge Function do portal não estão incluídos
  neste checkout. Não é possível conferir nem reproduzir as políticas ativas a
  partir somente destes arquivos.

Supabase
- Projeto Supabase dedicado ao portal, configurado separadamente da gestão interna.
- Antes de liberar ações administrativas do portal, mantenha no repositório a
  migração SQL e o código da Edge Function `client-projects`. A função precisa
  validar no servidor que o JWT pertence a owner/admin; ocultar botões no site
  não protege a função.
- Bucket client-documents privado.
- A chave no portal.js é publishable. Nunca incluir service_role ou chave secreta
  em arquivos públicos.
- Site URL e Redirect URLs configuradas para o endereço publicado e recuperação.

Antes de receber clientes
1. Confirmar que o cadastro público está desativado e que somente a equipe cria contas.
2. Confirmar que a Data API está habilitada para consultar as tabelas.
3. Testar com uma conta interna e vincular um projeto de teste em project_members.
4. Conferir atualização de andamento, mensagem e download de documento privado.
5. Remover a conta e os dados de teste antes do uso real, se necessário.

O portal não contém dados reais de clientes. A plataforma interna de orçamento continua separada.
